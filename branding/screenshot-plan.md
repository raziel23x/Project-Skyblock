# Project Screenshot Plan

## Purpose

Maintain a consistent set of current screenshots for CurseForge, GitHub, release announcements, and other public project pages.

Replace screenshots when visible blocks, models, GUIs, textures, names, or behavior no longer match the current release.

## Required Screenshots

### Project Overview

- A clean Skyblock base containing several Project Skyblock systems
- The project logo or title visible separately when appropriate
- No unrelated debug overlays
- No unfinished placeholder blocks

### Resource Generators

Capture:

- Cobblestone Generator
- Water Generator
- Lava Generator
- Manual extraction
- Automated output into compatible storage
- Visible generator particles

### Material Crusher

Capture:

- Exterior block from the front
- Exterior block while active
- Rotating gears
- Front processing chamber
- Rear vent effects
- GUI with energy, fuel, and progress visible
- Example automation setup

### Thermal Generator Mk I

Capture:

- Exterior front view
- Rear cooling fan and exhaust
- Active firebox
- GUI with fuel, lava, and FE visible
- Energy output into a cable network

### Energy Network

Capture:

- Basic Energy Cable straight run
- Corners and junctions
- Connection between generator and machine
- Structural Energy Frame where appropriate
- A compact network without visual clutter

### Reagents and Mixing Bowl

Capture:

- Red, Green, and Blue Reagents
- Matching storage blocks
- Particle effects
- Mixing Bowl recipe use
- Reusable crafting result

### Equipment

Capture:

- Full Flint equipment set
- Full Wooden equipment set
- Armor worn by a player or armor stand
- Tools arranged clearly

### Repair Gem

Capture:

- Repair Gem item
- Dropped-item aura
- Optional Curios integration when available
- Damaged equipment before and after repair, when the difference is clear

## Capture Standards

- Use the current release build.
- Use default or clearly identified resource packs.
- Use a consistent field of view.
- Use daylight unless night better demonstrates the feature.
- Hide unrelated HUD elements when possible.
- Do not show personal server addresses, account details, or private chat.
- Avoid excessive shaders unless a separate unshaded screenshot also exists.
- Use descriptive filenames.

## Screenshot Review Checklist

Before publishing:

- The feature still looks the same in the current build.
- The screenshot uses the current block and item names.
- No debug text or private information is visible.
- The image is sharp and correctly cropped.
- The description accurately matches the screenshot.
