## About-Panel Website

Use the CurseForge project page as the repository website when the public project page is available.

## Branding Rule

The GitHub About panel, README, CurseForge page, release descriptions, and project artwork must use the same:

- Project name
- Tagline
- Minecraft version
- Mod loader
- Feature terminology
- Support and issue links
