Project Skyblock 2.0 - Repair Gem and Generator Particle Effects

Adds:
- Dropped Repair Gem:
  - subtle green motes
  - occasional bright pulse
  - client-side only
  - configurable in projectskyblock-common.toml

- Cobblestone Generator:
  - stone dust and occasional ash

- Water Generator:
  - splash and occasional bubbles

- Lava Generator:
  - smoke and occasional lava pops

Install:
1. Extract into the project root.
2. Allow the four Java files to be replaced.
3. Run:
   gradlew.bat runClient
