Project Skyblock 2.0 - Reagent Block Forms

Adds:
- Red Reagent Block
- Green Reagent Block
- Blue Reagent Block
- Block items
- Original textures
- Original block and item models
- Blockstates
- Loot tables
- Creative-tab entries
- English names

Recipes are intentionally not included yet.

Install:
1. Extract this ZIP into the project root.
2. Replace the included files.
3. Run:
   gradlew.bat runClient

After testing:
   git add -A
   git commit -m "Add red green and blue reagent blocks"
   git push
