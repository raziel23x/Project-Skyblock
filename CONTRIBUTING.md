# CONTRIBUTING.md

Thank you for your interest in Project Skyblock.

Before writing code, adding content, or proposing a feature, please read:

1. PROJECT_CONSTITUTION.md
2. CIVILIZATION_BLUEPRINT.md
3. PROJECT_BIBLE.md
4. Relevant system documentation

## Philosophy First

This project is driven by design, not feature count.

Every contribution should answer:

- What problem does it solve?
- Why does it exist?
- Which Age of Civilization does it belong to?
- Does it complement vanilla?
- Does it respect the Project Constitution?

## Pull Request Expectations

- Keep changes focused.
- Document gameplay changes.
- Prefer data-driven implementations.
- Include migration notes if save compatibility changes.
- Avoid unrelated refactors.

## Feature Proposal Template

- Summary
- Purpose
- Gameplay impact
- Vanilla interaction
- Progression stage
- Systems affected
- Alternatives considered
- Risks
- Documentation updated?

No gameplay feature should be merged until its documentation exists.
