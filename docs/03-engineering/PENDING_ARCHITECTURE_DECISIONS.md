# Pending Architecture Decisions

> Status: **Working-session memory aid**
>
> This file records decisions discussed away from the development computer that still require
> repository review, formal documentation, implementation planning, or explicit closure.

## Workflow

At the beginning of a development session, review this file before selecting the next feature.

For each item:

1. compare it against the current repository;
2. identify the authoritative document it belongs in;
3. document or implement it when justified;
4. record tests or migration work;
5. remove it from this list only after the repository contains the durable result.

This file is not an alternative to ADRs, specifications, milestones, or the decision log. It prevents
important discussions from disappearing before they reach those documents.
