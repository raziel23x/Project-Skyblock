# Developer Guide

Project Skyblock is a NeoForge mod designed to integrate into many different modpacks.

## Goals

- Stable public APIs
- Data-driven systems
- Minimal hard dependencies
- Backwards-compatible save data
- Optional integrations

## Public Extension Points

- Datapacks
- KubeJS
- Tags
- JSON resources
- Registries
- Events

Contributors should expose new gameplay through these extension points whenever practical.
