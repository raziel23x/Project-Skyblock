# Resource Production

## Philosophy
Every essential resource should define:

- Bootstrap acquisition
- Renewable production
- Industrial-scale production

## Examples
Dirt
Stone
Clay
Sand
Metals
Wood
Organics

No resource should become permanently unobtainable.
