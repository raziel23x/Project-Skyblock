# Civilization Core Specification

## Purpose
Provide the overarching progression model for the mod.

## Design Goals
- Multiple valid progression paths.
- Reward knowledge before automation.
- Never force one technology chain.
- Keep vanilla mechanics relevant.

## Core Loop
Observe → Gather → Experiment → Produce → Automate → Expand

## Pillars
- Biology
- Agriculture
- Chemistry
- Metallurgy
- Engineering
- Logistics
- Research

## Acceptance Criteria
- Systems interact meaningfully.
- No required external mods.
- Fully data-driven where practical.
