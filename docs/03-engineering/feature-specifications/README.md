## Specification Standard

Every production specification should include:

- purpose;
- player experience;
- functional requirements;
- non-functional requirements;
- data model;
- extension points;
- compatibility;
- testing requirements;
- acceptance criteria.

A feature is not implementation-ready until its acceptance criteria are measurable.
