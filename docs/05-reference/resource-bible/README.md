## Resource Standards

Every resource must answer:

1. Why does it exist?
2. How is the first one obtained?
3. How does it become renewable?
4. How is it industrialized?
5. How does it interact with vanilla?
6. How does it support civilization?
7. Where does it fit in progression?

No resource should exist without a defined purpose.
