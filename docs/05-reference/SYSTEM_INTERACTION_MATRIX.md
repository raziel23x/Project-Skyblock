# System Interaction Matrix

| System | Primary Inputs | Primary Outputs | Supports |
|---|---|---|---|
| Biology | Organics, water | Compost, biomass | Agriculture, Chemistry |
| Agriculture | Soil, water, nutrients | Food, crops, biological inputs | Biology, Chemistry |
| Forestry | Saplings, land, time | Wood, leaves, resins | Biology, Construction |
| Ecology | Habitats, biodiversity | Environmental stability | Biology, Agriculture |
| Chemistry | Minerals, fluids, biomass | Reagents, treated materials | Metallurgy, Energy |
| Metallurgy | Ores, reagents, heat | Metals, alloys, components | Machines, Logistics |
| Energy | Fuels, motion, heat | Usable power | Machines, Logistics |
| Machines | Materials, energy, recipes | Processed resources | Every production system |
| Logistics | Containers, transport, control | Resource movement | Every system |
| Research | Observation, criteria | Discoveries, capabilities | Every system |
| Dimensional Science | Advanced materials, research | Dimensional resources | Mastery systems |

## Rule

Every major system should consume from or produce for at least one other system. Isolated systems require explicit design justification.
