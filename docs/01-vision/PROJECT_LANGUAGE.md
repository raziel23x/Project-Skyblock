# PROJECT_LANGUAGE.md

Project Skyblock uses consistent terminology.

| Avoid | Preferred |
|-------|-----------|
| Tech Tree | Knowledge Web |
| Tech Tier | Age of Civilization |
| Generator | Process or Production System |
| Grind | Progression |
| Upgrade | Engineering Advancement |
| Magic Ore | Dimensional Material |
| Endgame | Mastery |
| Automation Tier | Automation Stage |

## Tone

Documentation should:

- explain why before how;
- use consistent names;
- avoid duplicate terminology;
- prefer descriptive language over abbreviations.

When adding a new mechanic, first determine whether an existing term already describes it.
