# DESIGN_PATTERNS.md

## Purpose

Reusable design patterns ensure every gameplay system feels like part of the same game.

## Bootstrap Pattern

Every resource defines:

- Initial acquisition
- Renewable path
- Industrial path

## Automation Pattern

Manual
→ Assisted
→ Mechanical
→ Industrial
→ Automated

## Machine Pattern

Every machine documents:

- Purpose
- Inputs
- Outputs
- Power
- Automation role
- Vanilla interaction

## Review Pattern

Every feature answers:

1. Why does it exist?
2. What civilization problem does it solve?
3. Which existing systems does it connect to?
4. Does it obey the Constitution?
