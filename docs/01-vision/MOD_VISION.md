# Mod Vision

> **One Tree. Infinite Possibilities.**

Project Skyblock is a civilization-building systems mod that begins with a living tree suspended in the void. The player does not discover a finished world; the player builds one.

It complements vanilla Minecraft instead of replacing it.

## Core Principles

- The starting tree is the universal origin of mandatory progression.
- Discovery and understanding come before automation.
- Resources are created through understandable, renewable processes.
- Progression unlocks capabilities and connected systems, not only stronger numbers.
- Automation creates freedom from work the player has already mastered.
- Datapacks, KubeJS, configuration, and optional integrations remain first-class extension paths.
