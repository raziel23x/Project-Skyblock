# Starting Conditions

## One Tree. Infinite Possibilities.

Every Project Skyblock world begins in the void with a living tree.

The tree is the only universal starting guarantee. Its species may vary, and the platform beneath it may vary in size, shape, material, biome, or presentation. Those details belong to the world, datapack, or modpack author.

The invariant is simple:

> **If the player has the tree, the game is solvable.**

## Required Start

An official or compatible start must provide:

- one living tree;
- enough safe footing to begin harvesting it;
- access to the void as the defining world condition.

No specific platform dimensions, block palette, chest contents, or tree species are mandatory.

## The One-Tree Test

Every mandatory progression path must ultimately be reachable from the starting tree and the renewable systems unlocked from it.

A feature fails the One-Tree Test when it requires an unobtainable structure, biome, resource, mob, dimension, or external mod with no Project Skyblock path or configurable alternative.

Optional shortcuts and integrations may accelerate progression, but they must not become hidden hard requirements.
