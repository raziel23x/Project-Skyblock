# KNOWLEDGE_WEB.md

> Progress in Project Skyblock is driven by understanding, not by climbing a linear tech tree.

## Design Philosophy

Traditional progression asks:

"I crafted Machine B. What unlocks next?"

Project Skyblock asks:

"What have I learned about the world?"

Knowledge spreads outward, reconnects, and creates new opportunities.

# Cross Connections

Biology supports Agriculture.

Agriculture supports Chemistry.

Chemistry supports Metallurgy.

Metallurgy enables Engineering.

Engineering accelerates Biology.

Research improves every branch.

The web intentionally loops back on itself.

---

# Design Rules

1. Avoid single-path progression.
2. Encourage specialization.
3. Reward experimentation.
4. Let systems reinforce each other.
5. Manual understanding precedes automation.
6. Unlock capability through knowledge.

---

# Review Questions

When adding a feature ask:

- Which knowledge domain owns it?
- Which existing domains connect to it?
- Does it create a meaningful new connection?
- Does it open multiple future paths?
- Does it strengthen the web instead of extending a straight line?

If not, reconsider the design.

---

# Long-Term Vision

Players should never feel trapped on rails.

They should feel like scientists, engineers, farmers, builders, and explorers making discoveries that naturally expand what their civilization is capable of.
