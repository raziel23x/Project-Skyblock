# Gameplay Pillars

Project Skyblock is a civilization-building game that begins with one tree in the void.

## 1. Bootstrap from the Tree

The opening game is about turning a fragile start into stable, renewable capability. Early progression should teach the origin of each resource loop instead of handing the player finished infrastructure.

## 2. Creation over Exploration

The player does not discover a ready-made world. The player builds one.

Mandatory progression should come from processes the player can create, understand, expand, and automate. Exploration may provide optional rewards, alternate routes, and inspiration, but it must not silently gate the core game.

## 3. Automation Creates Freedom

Automation removes work the player has already learned and mastered. It should convert repetition into infrastructure, not erase the need to understand the process.

Manual → Assisted → Mechanical → Industrial → Automated

## 4. Systems over Items

Progression unlocks capabilities, relationships, and production networks—not merely stronger objects. Features should connect to multiple systems and create room for player-designed solutions.

## 5. Civilization from Nothing

The long-term objective is a functioning, sustainable world: food, materials, power, logistics, research, ecology, and shelter working together.

The player begins with a tree. The player ends with a civilization.
