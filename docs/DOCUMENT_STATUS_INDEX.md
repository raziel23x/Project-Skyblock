# Document Status Index

> **Canonical documentation-governance index.** This records the purpose and authority boundary of
> each tracked Markdown document after DOC-SPRING-001. It is not a substitute for the documents
> themselves; it prevents historical, planned, redirected, and current files from competing for
> authority.

## Status Key

- **Current** — authoritative for its stated subject.
- **Planned** — design direction; not implementation authorization.
- **Historical** — retained provenance; not current authority.
- **Reference** — non-production lookup/migration material.
- **Deferred** — intentionally retained for a later lifecycle phase.
- **Redirect** — compatibility pointer to a canonical document.
