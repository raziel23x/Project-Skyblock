Project Skyblock 2.0 - Mixing Bowl and Reagent Foundation

Adds:
- Reusable Mixing Bowl item
- Red Reagent
- Green Reagent
- Blue Reagent
- Original item textures
- Item models
- Tooltips and names
- Creative tab entries

Recipes are intentionally not included yet. This patch establishes the
functional items first so progression recipes can be redesigned later.

Install:
1. Extract this ZIP into the project root.
2. Replace the included files.
3. Run:
   gradlew.bat runClient

Test the Mixing Bowl with any temporary crafting recipe that consumes it.
It should remain in the crafting grid/output remainder rather than being lost.
